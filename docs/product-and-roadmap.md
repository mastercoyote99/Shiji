# 产品定义与路线

## 定位

Windows 优先的个人知识与灵感收藏工具。核心用户是希望保存工作资料、学习内容和兴趣素材，并再次找到、理解和利用它们的人。

## 要解决的问题

1. 保存渠道分散，忘记原资料位置。
2. 收藏数量增加，却没有形成回顾和行动。
3. AI 回答难以核对，敏感内容使用范围不清楚。

成功体验：几步完成收藏；通过自己的问题找到证据；从来源可靠的材料中得到一点可执行收获。

## 已完成

本地多类型文件收藏与管理、基础文本检索、可追溯 PDF 页码、按需云端生成、今日卡片、权限检查、回收/永久删除、改版页面。

## 下一阶段顺序

| 优先级 | 功能 | 验收方向 |
| --- | --- | --- |
| P1 | 截图 OCR | 明确本地/云端方式；原图与提取文字可对照；识别失败可纠正 |
| P1 | 检索评估集 | 自有非敏感资料配问题与正确来源页，比较命中和引用支持 |
| P2 | 本地语义检索+关键词组合 | 比较同义提问命中，保留权限过滤与页码 |
| P2 | 卡片反馈 | 有启发/太基础/不相关，减少重复并可解释选材 |
| P3 | 视频转录 | 保留时间点、处理状态与失败重试 |
| P3 | 日常自动运行 | 选择时间与素材范围；电脑关机行为明确；无重复调用 |

未安排自动同步社交平台收藏夹；须先核实平台允许的接口和访问方式。

## 度量计划（尚无数值结论）

- 从开始添加到保存成功的步骤/时间、保存失败原因。
- 正确来源页是否进入前 K 个片段。
- 答案关键论断是否由引用片段支持。
- 每日卡片有用性、重复率与实际行动完成情况。
- 单次生成耗时、失败率与费用（按实际响应记录）。

不能以“编号检查通过”代替准确率，也不能以一次成功运行推断长期稳定性。
