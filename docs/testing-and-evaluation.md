# 验证记录与验收

## 开发环境验证

当前 tests/test_storage.py 共 15 项测试：

- 原 9 列数据库迁移、历史卡片保留、重复初始化。
- 仅本地素材在网络边界被阻止，未授权拒绝发送。
- 检索后修改权限、内容、回收状态，旧快照不可发送。
- 合法请求通过模拟服务，输出不含密钥；length 截断提示。
- 两页合成 PDF 页码保留，空白页提示 OCR。
- 文件内容去重、旧文件哈希补算、回收站重复提醒。
- 永久删除原件/分块/记录、可选删除关联卡片；禁止直接永久删除正常素材。
- 问答可从单份文档返回超过两个片段。

界面使用 Streamlit AppTest 验证：新增到详情跳转、编辑、回收恢复、私密本地检索与发送禁用、模拟回答、今日保存与再次读取、PDF 按页选材、DELETE 确认。安装器备份与原数据保留在临时项目验证。

这些界面检查由开发时脚本执行，当前仓库中的可复现自动化文件是 15 项 storage 测试；未将临时界面脚本计为仓库测试套件。

## 用户反馈

已反馈：Windows 本地启动、迁移 D 盘、PDF 识别、问我的收藏、早期学习卡片生成成功。

后续反馈：PDF 在问答中难以找到，删除与用户预期不符。v0.4.1 已给出修复包，不能提前声称用户实际验收通过。

## 尚未验证

真实 API 在最新版本的完整回归、长时间稳定性、500+ 文档性能、多语言检索、真实扫描件 OCR、截图级多分辨率视觉验收、事实准确率。

## 发布前手动验收

1. 旧收藏与历史卡片仍在；新素材默认仅本地。
2. 添加文件失败保留输入，成功到详情；重复文件提示正确。
3. PDF 页数/内容正确，原文词能检索到目标页。
4. 按页入口可预览原文并加入回答依据。
5. 修改或回收素材后重新检索不使用旧内容。
6. 仅本地素材不可发送；公开测试素材可按授权生成。
7. 卡片引用编号与来源一致，并人工检查内容支持关系。
8. 用临时素材确认永久删除，保留真实资料备份。
