# 拾集 Shiji

**让收藏有回响：面向个人工作与兴趣素材的本地收藏、检索问答和每日知识卡片工具。**

将文字、文件、截图和平台分享链接收集在一起，再从已提取的内容中查找资料、生成带来源的回答与学习／创意／思考卡片。

当前版本：**v0.4.1** · Windows 本地 Web 应用 · Python / Streamlit / SQLite

> 本地保存、提取与检索，云端按需生成。不是完全离线 AI。图片和视频目前仅保存与预览；不自动同步抖音或小红书收藏夹。

## 为什么做拾集

个人资料往往散落在收藏夹、截图和下载文件夹里：保存容易，找回困难，更难转化成自己的知识。本项目从日常收集出发，逐步实现“收集 → 整理 → 找回 → 理解 → 形成行动”的使用流程。

## 当前能力

| 能力 | 已实现 | 边界 |
| --- | --- | --- |
| 素材收集 | 文字、PDF、TXT/Markdown、图片、视频、分享链接 | 链接不自动抓取内容 |
| 本地提取 | 文字型 PDF 页码提取、UTF-8 文本 | 扫描页需后续 OCR |
| 收藏管理 | 编辑、分类、标签、筛选、重复文件提醒、回收站和永久删除 | 备份与导出文件不随删除清理 |
| 检索问答 | 英文词与中文双字片段相关性检索、可选来源、PDF 按页问答 | 非向量语义检索 |
| 今日拾得 | 学习／创意／思考卡片，主题与素材筛选，历史保存 | 手动生成，无后台定时任务 |
| 隐私控制 | 默认仅本地、发送前检查权限与内容版本 | 数据库未加密，云端服务政策另行适用 |
| 记录导出 | 回答或卡片及引用片段导出 Markdown | 导出内容可能含私人资料 |

## 页面与使用路径

- **收藏库**：卡片浏览、关键词搜索（含提取正文）、空间／类型／隐私／标签筛选。
- **添加素材**：填写内容并上传附件，保存成功自动进入详情。
- **素材详情**：阅读与预览在左，管理操作在右，按页查看提取正文。
- **问我的收藏**：左侧回答，右侧选材与引用；可直接指定 PDF 页。
- **今日拾得**：选择主题和材料，生成卡片并保留历史。
- **回收站**：恢复素材，或输入 DELETE 后永久删除。

## 本地运行

需要 Python 3.12；在项目文件夹打开 PowerShell：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run .\app.py
```

打开 `http://127.0.0.1:8501`。程序默认绑定本机地址。

收藏和本地检索无需模型密钥。云端生成需在左侧“AI 设置与隐私”填写 OpenRouter key、模型 ID 并授权，再点击生成。默认模型 ID 来自开发时实际使用配置，不保证持续可用或免费。

## 首次体验

1. 添加一条公开测试笔记或文字型 PDF，检查提取结果。
2. 若准备调用云端，编辑该非敏感素材，取消“仅本地使用”。
3. 在问答中指定范围并检索，查看即将发送的片段。
4. PDF 未命中时展开按页入口，选择文件页作为依据。
5. 生成回答或今日卡片，对照来源检查内容是否受支持。

## 测试

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p test_storage.py -v
```

15 项离线测试通过（开发环境记录），覆盖数据库迁移、文件提取、请求权限、过期片段、回收站、永久删除、文件去重与模拟 API 响应。使用临时数据，无需真实 key。用户已反馈 PDF 提取、收藏问答与早期卡片生成成功；v0.4.1 的 Windows 实际体验待继续确认。

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `app.py` | 页面导航、收集、详情、编辑与回收站 |
| `storage.py` | SQLite、迁移、文件保存、分块、权限重查与删除 |
| `ai_features.py` | 检索、云端请求、问答与每日卡片 |
| `ui.py` | 视觉样式、安全文本展示 |
| `tests/test_storage.py` | 存储、权限和请求边界回归测试 |
